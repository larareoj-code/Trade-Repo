# Rainy Day Quest Maker

Parent-first printable indoor quest maker for safe family play. It produces clue cards, setup notes, route placement guidance, and a print layout.

## GitHub Status

Runbook published. Source batch queued from local root `work/rainy_day_quest_maker`.

## Safety Notes

No leaving home, climbing, hiding in unsafe spaces, food/medicine advice, dares, trademarks, or child-directed purchase prompts.

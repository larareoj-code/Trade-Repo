Privacy Note

Rainy Day Quest Maker is designed to run entirely in the user's browser.

Data handling

  • Quest settings are not sent to a server by this static MVP.
  • The active settings may be stored in browser localStorage on the current device.
  • JSON exports are created only when the user chooses to download them.
  • Print actions use the browser's standard print feature.

Third parties

The included MVP has no analytics, advertising, API, payment, tracking, or third-party font requests.

User responsibility

A grown-up should review every generated route and avoid unsafe locations, private information, and materials that are not appropriate for the household.

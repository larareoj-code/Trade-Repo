## Product title

Rainy Day Quest Maker - Printable Indoor Family Quest Builder

## Short description

Create safe, printable indoor clue-card quests for supervised family play. Runs locally in the browser with no account, subscription, API key, ads, or tracking.

## Full description

Rainy Day Quest Maker helps parents turn a quiet indoor afternoon into a structured, printable quest. Pick a theme, age band, difficulty, clue count, excluded rooms, and available supplies. The app generates a parent setup brief, safety review, route notes, and cut-apart clue cards.

The included MVP is local-first and deterministic. It does not collect child data, call an AI service, use tracking, or send information anywhere.

## Included

- Deterministic clue-card generator
- Parent setup brief
- Safety review
- Printable clue card layout
- Local JSON export
- Browser test page
- Privacy note and README

## Important note

A grown-up should place every clue, walk the route before play, and supervise the activity. Avoid unsafe rooms, stairs, heat, water, sharp objects, medicines, choking hazards, private storage, and unsupervised purchase prompts.

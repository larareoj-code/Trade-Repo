# Preview Caption Kit - Marketplace Listing Draft

## Short Description

Write cleaner screenshot captions, alt text, and preview carousel notes for small digital product listings.

## Full Description

Preview Caption Kit helps sellers package their product screenshots for storefronts. Enter a product name, what the screenshot shows, platform, and tone. The tool returns a caption set, carousel order, and alt text draft.

# Invoice Follow-Up Kit

## Short Description

Create calm invoice reminder emails, SMS notes, call scripts, and follow-up checklists for solo service businesses.

## Long Description

Invoice Follow-Up Kit is a lightweight browser tool for freelancers, consultants, studios, and service providers who need a clearer way to follow up on overdue invoices.

Enter the client name, invoice number, amount due, overdue timing, preferred tone, and next step. The kit produces:

- email reminder copy
- short SMS follow-up copy
- call opener script
- follow-up checklist
- review notes for safer usage

The tool runs locally in the browser. No API key, subscription, account, backend, analytics, or cloud storage is required.

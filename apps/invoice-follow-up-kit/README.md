# Invoice Follow-Up Kit

Invoice Follow-Up Kit is a local-first static web utility for solo service businesses. It creates invoice reminder copy, SMS notes, call scripts, and follow-up checklists from a few structured fields.

## Included

- `index.html`
- `styles.css`
- `app.js`
- `MARKETPLACE-LISTING.md`
- `PRIVACY.md`
- `LICENSE.txt`

## Boundaries

This is an operational writing aid, not legal, tax, collections, or financial advice. Users should review all messages against their contract terms, local rules, client relationship, and platform policies before sending. No payment, response, collection, or revenue outcome is promised.

## Local Use

Open `index.html` in a browser. No account, API key, backend, analytics, or cloud storage is required.

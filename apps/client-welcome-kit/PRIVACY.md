# Privacy Note

Client Welcome Kit is designed to run entirely in the user's browser.

## Data handling

- Project inputs are not sent to a server by this static MVP.
- The active project is stored in browser `localStorage` on the current device.
- JSON exports are created only when the user chooses to download them.
- Copy and print actions use browser features.

## Third parties

The included MVP has no analytics, advertising, API, payment, tracking, or third-party font requests.

If a seller adds hosting analytics, checkout, email capture, error reporting, or other services, this notice must be updated to identify those providers and their data practices.

## User responsibility

Users should avoid entering confidential client information, private personal data, or material they do not have permission to store on the device.

Client Welcome Kit provides organizational drafts and workflow templates. It does not provide legal advice and does not replace professional agreements, policies, or contracts.

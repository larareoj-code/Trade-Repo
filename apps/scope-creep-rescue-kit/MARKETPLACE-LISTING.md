# Scope Creep Rescue Kit - Marketplace Listing Draft

## Short Description

Estimate unpaid extra work and draft a clean client change-order note.

## Full Description

Scope Creep Rescue Kit helps freelancers and service providers turn extra client requests into a clearer scope conversation. Enter the project, extra hours, hourly value, and request. The tool returns an estimated extra-work value, a client note draft, and a boundary checklist.

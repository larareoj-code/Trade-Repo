# GitHub Pages Setup

This repository now includes a root static launcher:

- `index.html`
- `pages.css`
- `pages.js`

## Safe Publish Path

1. Open the repository settings for `larareoj-code/Trade-Repo`.
2. Go to Pages.
3. Set source to the default branch root.
4. Wait for Pages to build.
5. Verify the launcher and every app card before adding the URL to storefront listings.

Expected app links after Pages is enabled:

- `apps/shorts-hook-lab/index.html`
- `apps/client-welcome-kit/index.html`
- `apps/rainy-day-quest-maker/index.html`
- `apps/video-prompt-pack-builder/index.html`

- `apps/digital-bundle-builder/index.html`

## Guardrails

- This setup does not publish to Gumroad, Payhip, YouTube, email, or social channels.
- This setup does not make income, traffic, view, subscriber, or sales guarantees.
- ZIP and PNG artifacts remain local or release-only until a release/marketplace upload flow is used.
- Review each public page after GitHub Pages is enabled.
